Accessibility

Accessibility Statement

Last reviewed: 1 January 2025

Kairon Technology Ltd. is committed to ensuring that its website is accessible to all users, including those with disabilities. We strive to meet the Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA as a minimum standard across all pages of this site.

1. Our Commitment

We believe that everyone should be able to access information about Kairon Technology without barriers. Our design and development decisions are informed by accessibility best practices, and we regularly review our website to identify and address areas for improvement.

2. Conformance Status

This website is partially conformant with WCAG 2.1 Level AA. Partial conformance means that some parts of the content do not fully conform to the accessibility standard. We are actively working to address known gaps.

3. Technical Specifications

This website relies on the following technologies for conformance with WCAG 2.1:

  • HTML5
  • CSS3
  • JavaScript (ES2020)
  • ARIA landmark roles and attributes

4. Accessibility Features

The following accessibility features are implemented on this site:

  • Semantic HTML5 markup with appropriate heading hierarchy
  • ARIA roles and attributes for interactive components including modals, navigation, and buttons
  • Keyboard navigation support for all interactive elements
  • Focus indicators visible for keyboard users
  • Text alternatives (alt attributes) for all informative images
  • Sufficient colour contrast ratios in both light and dark modes
  • Light and dark mode toggle to accommodate visual preferences
  • Responsive design supporting zoom up to 400% without loss of functionality
  • Language attribute set on all pages to support screen reader pronunciation

5. Known Issues

We are aware of the following accessibility limitations and are working to resolve them:

  • Some SVG diagrams on the Technology page do not have full text equivalents for screen reader users. We plan to add descriptive text alternatives in a forthcoming update.
  • The language switcher dropdown may present navigation challenges for certain screen reader and keyboard-only combinations. An improved implementation is planned.

6. Alternative Formats

If you require information from this website in an alternative format — such as plain text, large print, audio description, or easy-read format — please contact us and we will endeavour to provide it within 10 working days.
