Compliance & Standards

Security Standards

Kairon Technology operates to the highest internationally recognised security and information assurance standards across all operational and digital functions.

Certifications

Compliance Framework

ISO 27001:2022

Information Security Management Systems. Kairon's information security programme is certified to the current edition of ISO 27001, encompassing our Belfast headquarters and all remote operational environments.

Certified — Valid to December 2026
SOC 2 Type II

Service Organisation Control 2, Type II attestation covering the security, availability, and confidentiality trust service criteria applicable to Kairon's data processing and client information management activities.

Attested — Annual Renewal
Cyber Essentials Plus

HM Government Cyber Essentials Plus certification, independently verified by an accredited certification body, confirming Kairon's networks are protected against the most prevalent cyber threats.

Certified — Current
BS 7858:2019

British Standard for security screening of individuals employed in a security environment. All Kairon operational personnel are screened to BS 7858, with senior roles subject to enhanced government vetting.

Compliant — All Personnel
Threat Monitoring

Kairon operates a 24/7 threat intelligence monitoring programme covering nation-state actors, criminal collectives, and emerging threat vectors across all client sectors and geographies of operation.

Active — Continuous
Incident Response

A tested information security incident response plan aligned to NCSC guidance, reviewed and exercised annually. ICO-reportable personal data breaches are notified within 72 hours.

Tested — Annual Exercise

Website Security

This website is delivered over HTTPS using TLS 1.3 with HSTS enforcement. Content Security Policy, X-Frame-Options, and other defensive HTTP headers are implemented to protect against common web-based attacks. The site does not use third-party tracking scripts or advertising networks.

Data Protection Measures

Personal data submitted through this website is encrypted in transit using industry-standard TLS and encrypted at rest using AES-256. Data is stored exclusively within UK-based infrastructure. Kairon does not use public cloud providers for any data classified above OFFICIAL.

Responsible Disclosure

Kairon Technology operates a responsible vulnerability disclosure programme. If you identify a genuine security vulnerability affecting our website or digital infrastructure, we ask that you report it privately to our security team before public disclosure, allowing us reasonable time to investigate and remediate.

Please report security vulnerabilities to: security@kairon-technology.com

We will acknowledge receipt within 48 hours and provide an initial assessment within five working days. We request a minimum of 30 days before any public disclosure. We do not pursue legal action against researchers who act in good faith and in accordance with these guidelines.

Penetration Testing

Kairon Technology's digital infrastructure undergoes independent penetration testing conducted by CHECK-approved testing organisations on an annual basis, with additional testing following significant system changes. Results are reviewed by the Chief Intelligence Officer and remediation is tracked to completion.

Incident Response

Kairon maintains a tested information security incident response plan aligned to NCSC guidance. The plan is reviewed and tested annually via tabletop exercises involving senior leadership. In the event of a personal data breach meeting the ICO notification threshold, Kairon will notify the relevant supervisory authority within 72 hours.
